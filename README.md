# Hadiya

Panel local para trabajar con Claude Code. Un ordenador, una persona, tu propia cuenta de Claude.

## Instalar

Descarga el paquete de tu sistema desde la [última release](https://github.com/andreavalerosanz-rgb/flows/releases/latest):

| Sistema | Archivo | Guía |
|---|---|---|
| Windows 10/11 | `hadiya-windows_<ver>.zip` | [docs/WINDOWS.md](docs/WINDOWS.md) |
| macOS 12+ | `hadiya-macos_<ver>.zip` | [docs/MAC.md](docs/MAC.md) |
| Linux | `hadiya-linux_<ver>.tar.gz` | [docs/LINUX.md](docs/LINUX.md) |

Sin administrador en ninguno. Para actualizar, vuelve a ejecutar el instalador del paquete nuevo: se conservan tus datos.

Construir los paquetes: `scripts/build-win.sh`, `scripts/build-mac.sh`, `scripts/build-linux.sh` (versión de `git describe`, tag `v<ver>`).
